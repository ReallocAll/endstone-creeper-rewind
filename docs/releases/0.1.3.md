# endstone-creeper-rewind v0.1.3

Consume and persist a restoration claim before world writes. Refuse restoration on failed or uncertain saves; interrupted claims are never replayed. Persist partial damage progress, avoid duplicate callbacks, and count per-block failures. Interrupted claims can lose unfinished repair rights.

Validation: automated regression tests and wheel validation. No real BDS runtime or power-loss/crash-kill validation was performed for this refactor. Existing configuration and data should be backed up before upgrading.

Installation: stop the server, activate its current Python environment, then run `uv pip install --upgrade ./endstone_creeper_rewind-0.1.3-py3-none-any.whl`. Restart the server. Do not copy this wheel into plugins; install it into the environment used by Endstone.
